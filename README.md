# TypeScript Project

This project is part of the Holberton School Web React curriculum.

It focuses on learning and applying TypeScript concepts including:
- Interfaces
- Classes
- Types
- Namespaces
- Advanced typing
- DOM manipulation

---

## 📁 Project Structure

Each task is organized in its own directory:

- `task_0` → Basic interface and DOM rendering
- `task_1` → Teacher interface
- `task_2` → Advanced types and functions
- `task_3` → Ambient namespaces and CRUD
- `task_4` → Namespaces & declaration merging
- `task_5` → Brand convention & nominal typing
